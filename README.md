# Homebrew Tap

Official [Homebrew](https://brew.sh) tap for my macOS applications and command-line tools.

## Installation

You can install an application directly without tapping first:

```bash
brew install --cask L4mbd4W0lf/tap/<app-name>
```

Or add the tap to Homebrew first, then install:

```bash
brew tap L4mbd4W0lf/tap
brew install --cask <app-name>
```

## Available Casks

| Cask | Description |
| :--- | :--- |
| `<app-name>` | Brief description of what your application does. |

## Troubleshooting

If you run into issues updating or installing, try updating Homebrew and refreshing the tap:

```bash
brew update
brew reinstall --cask L4mbd4W0lf/tap/<app-name>
```
